## 简介

TyMinder Core 是基于 KityMinder Core 修改的脑图可视化与编辑工具核心库。它提供了脑图数据的可视化展示和基本编辑功能，并增强了自由关联线功能。本指南将详细介绍如何在项目中集成 TyMinder Core，为新手和有经验的开发者提供完整的快速入门指导。

## 开发环境搭建

要开始使用 TyMinder Core 进行开发，您需要先搭建开发环境。以下是详细的步骤：

1. **安装 Node.js**  
   访问 [Node.js 官网](https://nodejs.org/) 下载并安装最新版本的 Node.js。Node.js 包含 npm（Node Package Manager），这是管理项目依赖的关键工具。

2. **安装 bower**  
   Bower 是一个前端包管理器，用于管理 JavaScript 库和其他前端依赖。通过 npm 全局安装 bower：
   ```bash
   npm install -g bower
   ```

3. **克隆项目并安装依赖**  
   将 TyMinder Core 项目克隆到本地后，进入项目目录并安装所有依赖：
   ```bash
   # 安装 npm 依赖
   npm install
   
   # 安装 bower 依赖
   bower install
   ```

完成以上步骤后，您的开发环境就准备就绪了。

## 构建脚本使用

TyMinder Core 使用 Grunt 作为构建工具，`package.json` 文件中定义了两个主要的构建脚本：

- **dev**: 启动开发服务器，实时预览更改
- **build**: 构建生产版本的文件

### dev 脚本

`dev` 脚本用于启动开发服务器，它会自动打开浏览器并监听文件变化，实时刷新页面。执行以下命令启动开发服务器：
```bash
npm run dev
```
此命令会启动一个本地服务器，默认打开 `dev.html` 文件，方便您进行开发和调试。

### build 脚本

`build` 脚本用于构建生产版本的文件，包括压缩 JavaScript 和 CSS 文件。执行以下命令进行构建：
```bash
npm run build
```
构建完成后，生成的文件将位于 `dist` 目录下，包括 `kityminder.core.min.js` 和 `kityminder.core.css`。

## 集成方式

TyMinder Core 支持两种集成方式：通过 `<script>` 标签引入和通过模块加载器（SeaJS）引入。下面详细介绍这两种方式。

### 通过 script 标签引入

这是最简单的集成方式，适合快速原型开发或简单的项目。只需在 HTML 文件中添加相应的 `<script>` 标签即可。

```html
<!-- 引入 Kity 图形引擎 -->
<script type="text/javascript" src="node_modules/kity/dist/kity.min.js"></script>

<!-- 引入 TyMinder Core -->
<script type="text/javascript" src="dist/kityminder.core.min.js"></script>
```

### 通过 SeaJS 模块加载器引入

对于复杂的项目，推荐使用 SeaJS 模块加载器来管理依赖。这种方式可以更好地组织代码，避免全局变量污染。

```html
<!-- 引入 SeaJS -->
<script type="text/javascript" src="node_modules/seajs/dist/sea-debug.js"></script>

<script type="text/javascript">
    seajs.config({
        base: './src'
    });
    
    define('start', function(require) {
        var Minder = require('kityminder').Minder;
        
        // 创建 Minder 实例
        var km = new Minder();
        km.setup('#minder-view');
    });
    
    seajs.use('start');
</script>
```

## Hello World 示例

本节将基于 `example.html` 和 `dev.html` 创建一个完整的 "Hello World" 示例，展示如何实例化 Minder 对象、设置根节点并渲染到页面。

### HTML 结构

首先，创建一个基本的 HTML 结构，包含一个用于渲染脑图的容器：

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>TyMinder Core Hello World</title>
    <link rel="stylesheet" href="src/kityminder.css">
    <style>
        #minder-view {
            position: absolute;
            border: 1px solid #ccc;
            left: 10px;
            top: 10px;
            bottom: 10px;
            right: 10px;
        }
    </style>
</head>
<body>
    <script id="minder-view" type="application/kityminder" minder-data-type="json">
    {
        "root": {
            "data": {
                "text": "Hello World"
            }
        }
    }
    </script>
</body>
</html>
```

### 初始化 Minder 实例

接下来，在页面底部添加 JavaScript 代码，初始化 Minder 实例并将其绑定到容器：

```html
<script type="text/javascript" src="node_modules/kity/dist/kity.min.js"></script>
<script type="text/javascript" src="dist/kityminder.core.min.js"></script>
<script type="text/javascript">
    // 创建 Minder 实例
    var km = new kityminder.Minder();
    
    // 设置并渲染到指定容器
    km.setup('#minder-view');
    
    // 禁用编辑模式
    km.disable();
    
    // 启用手动操作模式
    km.execCommand('hand');
</script>
```

这个示例展示了如何创建一个简单的脑图，其中包含一个根节点 "Hello World"。通过 `setup` 方法，Minder 实例会自动读取 `script` 标签中的 JSON 数据并渲染到页面上。

## 常见问题解决方案

在使用 TyMinder Core 时，可能会遇到一些常见问题。以下是这些问题的解决方案。

### SVG 渲染问题

由于 TyMinder Core 基于 SVG 技术实现，某些旧版浏览器可能不完全支持 SVG。确保使用支持 HTML5 的主流浏览器，如 Chrome、Firefox、Safari、Edge 或 Internet Explorer 10+。

如果在特定浏览器中出现渲染问题，请检查浏览器的兼容性设置，并确保没有禁用 SVG 支持。

### 模块加载错误

当使用 SeaJS 加载模块时，可能会遇到模块找不到或依赖关系错误的问题。确保 `base` 配置正确指向 `src` 目录，并且所有依赖模块都已正确安装。

```javascript
seajs.config({
    base: './src'  // 确保路径正确
});
```

此外，检查 `import.js` 文件中的依赖顺序，确保核心模块在功能模块之前加载。

### 其他常见问题

- **JSON 数据格式错误**：确保导入的 JSON 数据符合 TyMinder Core 的数据格式要求。
- **样式丢失**：确保正确引入 `kityminder.css` 文件，并检查路径是否正确。
- **事件监听失败**：确保在 Minder 实例初始化完成后再绑定事件监听器。
